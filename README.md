# TEG - The Education Group

TEG (The Education Group) is a premier overseas education consultancy providing expert guidance for international admissions, visa assistance, IELTS training, and career counseling. With over 15 years of excellence and 5000+ students placed worldwide, TEG bridges the gap between ambition and global opportunities.

## 🚀 Live Demo
Visit the website: [https://theeducationgroup.net/](https://theeducationgroup.net/)

## ✨ Key Features
- **Comprehensive Study Abroad Guidance**: Detailed information for 10+ destination countries including UK, USA, Canada, Australia, and more.
- **Medical Education Specialization**: Dedicated paths for MBBS, Nursing, Pharmacy, and Dental studies abroad.
- **BTEC Fast-Track**: Direct pathways to UK degrees through recognized vocational qualifications.
- **Premium User Experience**: Modern, responsive design with glassmorphism effects, smooth animations (AOS), and high-contrast visuals.
- **Admin Hub**: Secure dashboard for managing student inquiries and site settings.
- **SEO & GEO Optimized**: Fully optimized for search engines and generative engine discovery with rich schema markup.

## 🛠️ Tech Stack
- **Frontend**: HTML5, Vanilla CSS3 (Custom properties, Flexbox/Grid), Tailwind CSS (for Admin Hub), JavaScript (ES6+).
- **Backend/Database**: Firebase (Firestore) for inquiry management.
- **Deployment**: Vercel.
- **Animations**: AOS (Animate On Scroll).
- **Icons**: Font Awesome 6.

## 📁 Project Structure
- `index.html`: Main landing page.
- `study-abroad.html`: Exploration of global destinations.
- `services.html`: Detailed breakdown of TEG offerings.
- `happy-students.html`: Student success stories and testimonials.
- `about.html`: Company history, mission, and team.
- `contact.html`: Inquiry and lead generation forms.
- `admin.html` & `settings.html`: Internal management dashboards.
- `style.css`: Global styles and design tokens.
- `script.js`: Shared interactive components and performance optimizations.
- `firebase-config.js`: Firebase integration for data handling.

## 🔧 Installation & Local Development
1. Clone the repository:
   ```bash
   git clone https://github.com/ruthwikreddy/teg.git
   ```
2. Open `index.html` in your browser or use a live server extension.
3. For the build process (replacing environment variables):
   ```bash
   npm install
   npm run build
   ```
